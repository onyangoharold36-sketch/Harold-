# Harold- Art Portfolio

A clean, responsive single-page portfolio website for an artist. It includes a hero section, work gallery, artist statement, collection highlights, and contact call-to-action.

## Run locally

Open `index.html` in a browser, or serve the folder with a small local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure
- `styles.css` — layout and visual design
- `script.js` — gallery filtering behavior
